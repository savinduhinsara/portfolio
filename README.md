# SAVINDU.SYS — Futuristic Portfolio

A complete static, responsive portfolio website for Savindu Hinsara.

## Files
- `index.html` — structure/content
- `style.css` — responsive futuristic UI
- `script.js` — interactions and animations

## Run
Just open `index.html` in a browser.

For the best experience, serve the folder with any local static server, e.g. VS Code Live Server.

## Included features
- Fully responsive desktop/tablet/mobile layout
- Futuristic dark UI with glass panels
- Animated orbit hero
- Matrix-style background
- Scanline/noise visual layer
- Typewriter terminal prompt
- Mobile navigation
- Project category filtering
- Interactive terminal with commands
- Command palette (`Ctrl/Cmd + K`)
- Keyboard navigation in command palette
- Contact form demo with clipboard packet
- Scroll-to-top button
- Reduced-motion support
- Semantic sections and accessible labels
- No external JS libraries required

## Personalization
The portfolio deliberately avoids inventing private contact information. Replace the three social placeholder links in `index.html` with your real profiles when ready.

The skill percentages are presentation values, not objective measurements—edit them freely in `index.html`.
